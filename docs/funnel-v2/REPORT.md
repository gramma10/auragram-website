## 2. Τελική λίστα analytics events

Στέλνονται: `hero_cta_click` · `agent_card_view` · `calculator_used` · `calculator_result_view` · `pilot_section_view` · `about_page_view` · `form_start` · **`lead_submit`** · `scroll_75` · `service_tab_view` · `industry_view`.

- `lead_submit` { `industry`, `utm_source`, `utm_campaign`, `has_calculator` } — **μόνο** μετά από επιτυχή απάντηση του server· όχι σε αποτυχία παράδοσης.
- Meta Pixel: το `lead_submit` στέλνεται ως standard **`Lead`** (`fbq('track','Lead',…)`)· όλα τα άλλα ως `trackCustom`.
- Αφαιρέθηκαν: `booking_complete`, `form_submit`.
- Απομένουν στο type αλλά **δεν στέλνονται ποτέ** (νεκρά από πριν): `chat_opened`, `chat_booked`.
- Κενές τιμές στέλνονται ως `(none)` (π.χ. `utm_source: "(none)"` όταν δεν υπάρχει UTM).
